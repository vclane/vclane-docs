# Flutter Mobile Application

The Flutter application provides the user interface for monitoring and controlling traffic infrastructure.

## Technology Stack

| Component         | Technology                    |
| ----------------- | ----------------------------- |
| Framework         | Flutter                       |
| Language          | Dart                          |
| Authentication    | Firebase Authentication       |
| Database          | Cloud Firestore               |
| Real-Time Updates | Firestore Streams / WebSocket |
| API Communication | Dio / HTTP Client             |
| Video Playback    | WebRTC / RTSP Player          |
| State Management  | Riverpod / Bloc               |
| Push Notification | Firebase Cloud Messaging      |
| Local Storage     | Hive / Shared Preferences     |

## Key Features

**Authentication** — Secure login, Firebase authentication, user session management, role-based access control.

**Traffic Dashboard** — Live intersection overview, traffic density information, device status monitoring, traffic statistics visualization.

**Live Video Monitoring** — View camera streams, multiple intersection support, low-latency playback, full-screen monitoring.

**Device Management** — View connected devices, monitor device health, check online/offline status, receive device alerts.

**Traffic Control** — Traffic signal override, remote commands, intersection group management, command execution monitoring.

**Notifications** — Alerts for device disconnection, traffic congestion, system events, critical conditions.
